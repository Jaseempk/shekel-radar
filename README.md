## What I did vs. what only you can do

**Done for you (in this folder):** the case study, all the scripts, the LinkedIn rewrite, the portfolio site code, both demo repos, and the prospect research.

**Only you can do these — they're your identity, and that's the point:**
1. **Replace the `[bracketed]` numbers** in the case study with real figures.
2. **Record the 90-second Loom** of your lead-scoring pipeline running (your screen).
3. **Deploy the site** (one command — see below) and paste the LinkedIn rewrite.
4. **Send** the outbound and **post** the Reddit/LinkedIn answers from your accounts.
5. **Take the calls** and close.

That's ~30–45 min/day of human work. Everything else is prepped.

## Deploy the site (fastest options)

The site is a single static file — no build step.

- **Cloudflare Pages:** `npx wrangler pages deploy site --project-name=jasim-automation`
- **Netlify:** drag the `site/` folder onto app.netlify.com/drop
- **Vercel:** `cd site && npx vercel --prod`
- **Test locally:** just open `site/index.html` in a browser.

Add your real Cal.com link and email in `site/index.html` (search for `REPLACE_`).
